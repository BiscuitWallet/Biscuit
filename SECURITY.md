# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Write to
[biscuitwallet@tutamail.com](mailto:biscuitwallet@tutamail.com), with enough detail for us
to reproduce it: the version, the system, the steps, and what an attacker could do.

We answer as soon as we can, fix confirmed issues first, and credit you in the release
notes if you wish.

## What is in scope

The code of the latest release published on
[biscuitwallet.com/download](https://biscuitwallet.com/download/), built and signed by us
(see [Verifying your download](https://biscuitwallet.com/docs/verify/)). Issues that come
from Feather Wallet or Monero are welcome too; we pass them on upstream.

Biscuit does not run a bug bounty program for now.

## Release signing key

Releases and updates are signed with this key, also built into the app:

| Name | Fingerprint |
|---|---|
| Biscuit Wallet releases | `D714 332E 6101 C1DA AC60  E644 202F 1FA3 98DE CEFA` |

The public key is published at
[biscuitwallet.com/files/releases/biscuit-release-key.asc](https://biscuitwallet.com/files/releases/biscuit-release-key.asc).

Nobody from Biscuit will ever ask for your seed, your password or your private keys.

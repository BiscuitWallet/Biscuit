Hardware wallets

With a hardware wallet, your Monero keys stay on the device: Biscuit asks it to sign each payment, and you confirm on its screen. This covers Monero; Bitcoin and Litecoin in Biscuit keep their own seed in your encrypted wallet file.

Supported devices

LedgerNano S, Nano S Plus, Nano X, Stax, Flex
TrezorModel T, Safe 3, Safe 5

The Trezor Safe 7 isn’t supported yet: it uses a new communication protocol that Monero’s code doesn’t speak yet.

Setting it up

  1. Connect the device. On a Ledger, open the Monero app; on a Trezor, unlock it.
  2. In Biscuit, choose Restore wallet from… › Hardware device and the device type.
  3. Choose Create a new wallet file from device if this device never held Monero, or Restore a wallet from device if it did. For a restore, enter the restore height, or the date you got the device.
  4. Choose a name and a password for the wallet file.

To check an address on the device’s screen, right-click it on Receive › Show on device. Building a payment on a device can take a minute or more.

On Linux

Linux needs udev rules before Biscuit can reach the device. Install them once, from Ledger or Trezor, then reconnect the device.

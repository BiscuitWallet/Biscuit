Keyboard shortcuts and command line

On a Mac, use ⌘ instead of Ctrl.

Everyday

Ctrl+FSearch bar
Ctrl+OOpen wallet
Ctrl+NNew or restore wallet
Ctrl+WClose wallet
Ctrl+LLock wallet
Ctrl+Alt+SSettings
Ctrl+DDebug info

Advanced

Ctrl+UUpdate balance
Ctrl+SSave the wallet (Biscuit saves by itself anyway)
Ctrl+RRefresh the lists. Avoid it while the wallet synchronizes.
Ctrl+KIn the wallet wizard: dice entropy on the new seed page, seed recovery on the restore page

Command line

--stagenet, --testnetMonero’s test networks, see Advanced tools
--use-local-torUse the Tor installed on your system instead of Biscuit’s
--quietLess output in the terminal
--version, --helpThe version, or this list

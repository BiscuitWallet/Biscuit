Install on Windows

Biscuit runs on Windows 10 and 11, 64-bit. There are two files on the download page: an installer, and a portable version that runs from any folder.

With the installer

  1. Download biscuit-<version>-win-installer.zip and verify it.
  2. Unzip it and run BiscuitSetup-<version>.exe.
  3. Follow the steps. Biscuit is installed in Program Files\Biscuit, with a Start menu entry.

To remove it, use Settings › Apps like any other program. Your wallets stay in Documents\Biscuit\wallets: removing Biscuit never deletes them.

Portable version

Unzip biscuit-<version>-win.zip in a folder of your choice and run biscuit-<version>.exe. Keep biscuit-swapd.exe next to it: atomic swaps need it.

To keep your wallets and settings in that same folder too, on a USB drive for example, turn on portable mode.

“Windows protected your PC”

The first time, SmartScreen may stop Biscuit with this message. Our files aren’t signed with a Microsoft certificate, so Windows doesn’t know them yet. Once you have verified the file, click More info, then Run anyway.

Some antivirus programs also flag Biscuit as a coin miner. It isn’t one: Monero’s code contains the algorithm Monero is mined with, and some scanners flag that code on sight. Biscuit never mines. Verify the file, then allow it in your antivirus.

I2P, SOCKS5 and offline mode

Besides its own Tor, Biscuit can use I2P or any SOCKS5 proxy, or no network at all. Everything is in Settings › Network › Proxy.

I2P

  1. Install and start an I2P router, such as i2pd.
  2. In Biscuit, set Proxy to i2p, with its SOCKS address (i2pd uses 127.0.0.1:4447), and apply.

With Let Biscuit manage this list ticked on the Node tab, Biscuit connects to a Monero node on I2P from its built-in list. Prices and the Journal aren’t fetched over I2P. Bitcoin and Litecoin go through the same proxy, and public Electrum servers usually can’t be reached that way: use your own server on your local network.

Your own SOCKS5 proxy

Set Proxy to socks5 and enter its host and port. A Tor you run yourself counts too: choose Tor and untick Automatic. Biscuit treats any proxy like Tor mode: exchange swaps are off.

Offline mode

Settings › Network › Offline › Disable all network connections (offline mode) stops every connection. Biscuit then can’t sync or send, but it can sign: that’s the mode for the offline computer in offline signing.

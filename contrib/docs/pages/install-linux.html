Install on Linux

Biscuit runs on 64-bit Linux (x86_64) with glibc 2.31 or later. Atomic swaps need glibc 2.34 or later: Ubuntu 22.04, Debian 12, Fedora 35 and newer all have it. The download page also gives each command ready to paste.

AppImage, for any distribution

Unzip biscuit-<version>-linux-appimage.zip and run the .AppImage. On GNOME, right-click it and choose Run as a Program, or make it executable from a terminal:

chmod +x biscuit-*.AppImage
./biscuit-*.AppImage

To add it to your applications menu, use Tools › Create desktop entry in Biscuit, or an AppImage manager such as Gear Lever. The AppImage updates itself.

Packages

DistributionCommand
Debian, Ubuntu, Mintsudo apt install ./biscuit_<version>-1_amd64.deb
Fedorasudo dnf install ./biscuit-<version>-1.x86_64.rpm
openSUSEsudo zypper install --allow-unsigned-rpm ./biscuit-<version>-1.x86_64.rpm
Arch, Manjarosudo pacman -U biscuit-<version>-1-x86_64.pkg.tar.zst

A package adds Biscuit to your applications menu. Biscuit tells you when a new version is out; install the new package the same way to update. Installing a new package over an old one replaces it, so you never end up with two versions.

Any distribution, without installing

Unpack biscuit-<version>-linux-x86_64.tar.gz and run biscuit. Keep biscuit-swapd next to it: atomic swaps need it.

Hardware wallets on Linux

Linux needs udev rules before a program can talk to a Ledger or Trezor. See Hardware wallets.

In Tor Browser

Tor Browser offers the onion address by itself when you open biscuitwallet.com. It serves the same pages and the same files. Check the address against the one above, or the one on our GitHub, before trusting it.

In the app

In Tor mode, Biscuit fetches prices, the Journal and updates from this onion, so that traffic never leaves Tor. If the onion can’t be reached, it falls back to biscuitwallet.com, still through Tor. The exchange swap service isn’t on the onion: exchange swaps never work through Tor.

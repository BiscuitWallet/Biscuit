Portable mode

In portable mode, Biscuit keeps its wallets, settings and Tor data in a folder next to the program, instead of your user folders. Handy on a USB drive or an encrypted volume.

Turning it on

Create an empty file named .portable or portable.txt in the same folder as Biscuit: next to biscuit-<version>.exe on Windows, or next to the AppImage on Linux. Start Biscuit: it finds the file and stores everything in a biscuit_data folder beside it.

Settings › Storage › Paths then says Portable mode is enabled.

Good to know

  • On Tails, portable mode is always on: that’s how your wallets survive a restart in the Persistent folder.
  • Wallets you already have elsewhere aren’t moved. Open them with File › Open wallet, or copy their files into biscuit_data/wallets.
  • Use the portable zip on Windows and the AppImage on Linux. The installer and the Linux packages install Biscuit in a system folder, where this doesn’t make sense.

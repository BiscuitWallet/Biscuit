Biscuit won't start

Start Biscuit from a terminal: its messages there usually say what’s wrong. Send them to us when you report the problem.

From a terminal

Windows
Press Windows+R, type cmd, press Enter. Drag Biscuit’s .exe into the window and press Enter.
macOS
Open Terminal and run /Applications/Biscuit.app/Contents/MacOS/biscuit.
Linux and Tails
Open a terminal, drag the AppImage into it and press Enter. If you installed a package, run biscuit.

Common causes

  • macOS says it can’t verify Biscuit: see Install on macOS.
  • Windows or an antivirus blocks it: see Install on Windows.
  • The AppImage does nothing on Linux: make it executable (chmod +x). On older systems, check the glibc version in Install on Linux.
  • An old version opens: two copies are installed, an old package and a newer AppImage for example. The applications menu may start the old one. Remove the old one, or install the new package over it.
  • Tor doesn’t connect: open Settings › Network › Proxy › Show status to see Tor’s log. Some networks block Tor.

Starting fresh

If Biscuit starts but behaves strangely, quit it and rename settings.json in the settings folder. Biscuit starts as on the first launch, with default settings. Your wallets aren’t in that folder and aren’t affected.

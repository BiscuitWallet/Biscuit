Signed messages

Signing a message with an address proves you hold that address, without sending anything. Use Tools › Sign/verify message and pick the coin.

Signing

  1. Type the message. It can be several lines, or empty if you only want to prove ownership.
  2. Choose the address. For Monero, any of your subaddresses; for Bitcoin and Litecoin, any address of the selected wallet.
  3. Click Sign, then Copy to clipboard to copy the message, the address and the signature together.

Whoever checks it needs all three: the message, the address and the signature.

Verifying

Paste the message exactly as written (it is case-sensitive), the address and the signature, then click Verify.

  • Monero signatures start with SigV2.
  • Bitcoin and Litecoin signatures use the format of Electrum, Sparrow and Bitcoin Core. Verifying works with any address type, legacy ones included.

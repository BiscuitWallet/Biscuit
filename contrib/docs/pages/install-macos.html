Install on macOS

Biscuit runs on macOS 14 Sonoma and later, on Macs with Apple Silicon and on Intel Macs.

Which file?

Open the Apple menu › About This Mac. If it says Chip (M1, M2, M3…), take the Apple Silicon file. If it says Processor (Intel), take the Intel one.

Install

  1. Download the zip and verify it.
  2. Unzip it and move Biscuit to your Applications folder.

Opening it the first time

macOS blocks Biscuit the first time, because it isn’t notarized by Apple. Notarizing would tie every release to a name and an Apple account, so we don’t. To allow it once:

  1. Open Biscuit. macOS says it can’t verify it: click Done.
  2. Open System Settings › Privacy & Security, scroll down to “Biscuit was blocked” and click Open Anyway.
  3. Confirm with your password or Touch ID.

From then on, Biscuit opens normally. Verify the file before you do this, so you know you’re allowing our file and not someone else’s.

Updates and removal

When a new version is out, Biscuit offers to replace itself in place. To remove it, drag it from Applications to the Bin. Your wallets stay in the Biscuit/wallets folder of your home folder.

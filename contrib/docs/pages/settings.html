All settings

Open the settings with the gear in the status bar, File › Settings, or Ctrl+Alt+S. Here is every page.

Appearance

Theme
Light or dark. The theme button in the status bar switches too.
Amount precision, Date format, Time format
How numbers and dates are shown.
Balance display
Total, spendable plus unconfirmed, or spendable only. See Balance.
Fiat currency, Show fiat balance in statusbar
Your currency, and whether the status bar shows the total in it.

Network

Node
Public nodes or your own. See Nodes.
Proxy
Tor, I2P, SOCKS5 or none, and Monero node traffic. See Tor mode and I2P, SOCKS5, offline.
Public data
Obtain third-party data: enabled, Tor only or disabled. See Prices and other data.
Offline
Disable all network connections.
Bitcoin & Litecoin
Your own Electrum servers. See Electrum servers.

Storage

Paths
The wallet folder, the settings folder and the program folder, with buttons to open them. See Wallet files and folders.
Logging
Write Monero’s log to disk, and how much. Off by default. Logs can contain transaction IDs: share them with care.
Misc
Remember recently opened wallets, for File › Recently open.

Display

Hide balance
For when people can see your screen.
Hide update notifications, Hide transaction notifications
Fewer pop-ups.
Warn before opening external link
Asks before opening your browser.
Lock wallet after inactivity, Lock wallet after minimizing the window
See Password and locking.
Show tray icon, Hide window to system tray when minimized
Keep Biscuit in the system tray.

Transactions

Multibroadcast outgoing transactions
Send each Monero payment to several nodes.
Always open advanced transaction dialog
Show the full details of every Monero payment before confirming.
Require password to spend
Ask for the password before each payment.
Manual fee-tier selection, Subtract fee from outputs
See Fees and confirmations.

Plugins

Turn the parts of the Home tab on or off, and the Swap tab.
